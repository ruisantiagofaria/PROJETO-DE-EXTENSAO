#PROJETO DE EXTENSÃO – Memorial Vida Eterna

##Desenvolvimento de um MVP (Mínimo Produto Viável) de software para gestão de uma organização.

Projeto interdisciplinar desenvolvido pelos alunos do 3º semestre do curso de Sistemas de Informação da Fatec Mauá, com foco na análise e no desenvolvimento de uma solução para a área logística de uma organização cemiterial.

## Objetivo do projeto

Desenvolver um MVP de software voltado à gestão logística do Memorial Vida Eterna Serviços Cemiteriais Ltda., buscando centralizar informações, organizar processos e facilitar o gerenciamento das atividades da organização.

A proposta surgiu a partir da identificação de dificuldades relacionadas ao uso de documentos físicos, planilhas independentes e processos manuais.

## Sobre a organização

O Memorial Vida Eterna é uma organização do segmento cemiterial, responsável por atividades relacionadas à administração de jazigos, registros de sepultamento, exumações, atendimento às famílias e gestão documental.

O projeto concentra-se na área logística, considerando os processos de transporte, sepultamento, controle de prazos e organização das ordens de serviço.

## Requisitos funcionais

Durante o levantamento de requisitos, foram identificadas oito funcionalidades principais para o sistema:

1. Cadastro do falecido, incluindo verificação de gratuidade ou tarifa social.
2. Transporte do falecido.
3. Efetuação do sepultamento.
4. Retirada do corpo da sepultura (exumação).
5. Registro do falecimento no livro.
6. Reserva de espaço para velório.
7. Preparação da cerimônia de despedida.
8. Captação de clientes por meio de chatbot.

## Etapas de desenvolvimento

O projeto foi dividido em quatro etapas principais:

- Engenharia de Software: levantamento e especificação dos requisitos, elaboração dos fluxos de eventos e diagramas de casos de uso.
- Linguagens de Programação I: desenvolvimento do site do MVP, implementação das funcionalidades e realização de testes.
- Banco de Dados: modelagem e implementação do banco de dados utilizando MySQL.
- Gestão de Equipes: organização das atividades, divisão de responsabilidades e acompanhamento da participação dos integrantes.

## Banco de dados

O banco de dados foi desenvolvido no MySQL Workbench e implementado em MySQL, contando com 11 tabelas:

- Administrador
- ResponsavelLegal
- Jazigo
- Falecido
- EquipeTrabalho
- Ferramenta
- EquipeFerramenta
- OrdemServico
- FichaControleTempo
- LivroRegistro
- ReservaVelorio

O modelo utiliza chaves primárias, chaves estrangeiras, restrições e relacionamentos para manter a organização e a integridade das informações.

- Melhor organização das ordens de serviço.
- Maior controle dos processos logísticos e dos prazos de exumação.
- Possibilidade de futuras melhorias e expansão do sistema.
